## 机器人简介

- **主控**：STM32F103C8T6（HAL 库，STM32CubeMX + CLion 构建）
- **驱动**：DRV8833 双路 H 桥 ×2，驱动 4 路 TT 马达 + 60mm 麦克纳姆轮全向底盘
- **执行机构**：SG90 ×2 + MG996R ×1 舵机机械臂（四自由度，连杆 + 舵机方案）
- **控制方式**：PS2 无线手柄手动遥控（SPI1 通信），双摇杆映射为 vx / vy / ω 麦轮解算
- **调试通道**：USART1（PA9 / PA10，115200，8N1）
- **整机**：约 1.9kg，约 ¥176.74 / 台（两台 ¥353.48，预算上限 ¥400）
